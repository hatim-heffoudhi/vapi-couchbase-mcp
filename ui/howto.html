How to test Jack

One call, one OTP, then order lookup, cancel, and supervisor approvals against Couchbase through MCP.

Pages

  1. Shop — buy a product. The order is written to order-demo._default.orders.
  2. Supervisor — OTP codes and Accept / Reject for date changes and late cancellations.
  3. Mailpit — OTP and confirmation emails for this local demo.
  4. Cluster UI — Buckets → order-demo → Documents.

MCP demo with Jack

  1. Write path: the shop inserts JSON orders into order-demo._default.orders.
  2. Read path: Jack uses Couchbase MCP (read-only) — get_document_by_id for order-1001 in bucket order-demo scope _default, or SQL++ such as SELECT * FROM `order-demo`.`_default`.`orders` WHERE order_id = 'ORD-1001'.
  3. Analytics: after the first OTP, ask how many orders are processing, the sum of totals, or which deliveries are still upcoming.
  4. Cancel: a new shop order (processing, under six hours) cancels immediately if you say you placed it by mistake. ORD-1001 is processing from last week and needs Supervisor Accept. ORD-1002 is shipped — cannot cancel; only the delivery date can be updated. ORD-1003 is delivered — cannot cancel or change the date.
  5. Human-in-the-loop: a date change or late cancellation is not written through MCP. You Accept on Supervisor; Jack checks quickly until it is approved, then speaks the result.

Test script

  1. On Shop, buy a product as Hatim. Note the new order number.
  2. Click Call support. Allow the popup. Wait until you hear Jack’s hello.
  3. Ask for that new order. Give the number. Read the OTP from Supervisor or Mailpit. He should not ask for OTP again later in the same call.
  4. Say you placed it by mistake. He should cancel it immediately.
  5. Ask about ORD-1001 (processing, last week). Ask to cancel. Keep the call open, open Supervisor, click Accept. Jack should say it is approved without a long pause.
  6. Ask to cancel ORD-1002 (shipped). He should refuse and offer a date change instead.
  7. Ask to change a delivery date on ORD-1002. Accept or Reject on Supervisor. Jack should speak the outcome.
